# Getting Started

Welcome to **excel-to-sql**, a powerful CLI tool and Python SDK for importing Excel files into SQLite databases with advanced data transformation, validation, and quality profiling features.

## What is excel-to-sql?

excel-to-sql simplifies the process of importing Excel data into SQLite databases. It provides:

## Key Features

### 1. Auto-Pilot Mode ⭐
The **star feature** of excel-to-sql. Automatically detects:
- Primary and foreign keys
- Value mappings (e.g., "1"/"0" → "Active"/"Inactive")
- Data quality issues with actionable recommendations
- Optimal data types for each column
- French code translation (ENTRÉE→inbound, SORTIE→outbound)

### 2. Flexible Transformations
- **Value Mappings**: Transform codes into human-readable values
- **Calculated Columns**: Create derived columns using SQL expressions
- **Validation Rules**: Ensure data integrity with 7+ validator types
- **Custom Hooks**: Execute code before/after import and export

### 3. Data Quality Profiling
- Multi-dimensional quality scoring (0-100) with letter grades (A-D)
- Issue detection: null values, duplicates, type mismatches
- Statistical analysis: value distributions, outliers
- Exportable HTML quality reports

### 4. Python SDK
Complete programmatic access for:
- Automation workflows
- CI/CD integration
- Custom data pipelines
- Batch processing
