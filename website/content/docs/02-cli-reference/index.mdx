# CLI Reference

Complete reference for all excel-to-sql CLI commands.

## Available Commands

```bash
excel-to-sql --help
```

**Core Commands:**
- [`init`](/docs/cli-reference/init) - Initialize project structure
- [`import`](/docs/cli-reference/import) - Import Excel files
- [`export`](/docs/cli-reference/export) - Export to Excel
- [`magic`](/docs/cli-reference/magic) - Auto-Pilot mode
- [`config`](/docs/cli-reference/config) - Manage configurations
- [`status`](/docs/cli-reference/status) - View import history
- [`version`](/docs/cli-reference/version) - Show version

## Global Options

All commands support these options:

```bash
--help          Show help message
--verbose, -v   Enable verbose output
--quiet, -q     Suppress output
```

## Common Patterns

### Import with Auto-Detection

```bash
excel-to-sql magic --data ./excels
```

### Manual Configuration

```bash
excel-to-sql init
excel-to-sql config add --type mytype --table mytable --pk id
excel-to-sql import --file data.xlsx --type mytype
```

### Export Query Results

```bash
excel-to-sql export --query "SELECT * FROM products WHERE price > 100" --output results.xlsx
```

## Command Flow

Typical workflow:

1. `excel-to-sql init` - Create project
2. `excel-to-sql config add` - Configure type
3. `excel-to-sql import` - Import data
4. `excel-to-sql export` - Export results
5. `excel-to-sql status` - View history

## Exit Codes

- `0` - Success
- `1` - Error occurred
