## Key Features

- **Smart Import**: Automatic schema detection with intelligent type inference
- **Auto-Pilot Mode**: Zero-configuration setup with pattern detection and quality scoring
- **Data Transformations**: Value mappings, calculated columns, custom hooks
- **Quality Analysis**: Comprehensive validation with detailed HTML reports
- **Python SDK**: Full programmatic access for automation
- **Rich CLI**: Beautiful terminal output with progress tracking

## Getting Help

```bash
# CLI help
excel-to-sql --help
```
