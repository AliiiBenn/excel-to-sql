# Installation

## Using pip (Recommended)

```bash
pip install excel-to-sql
```

## Using uv (Faster)

```bash
uv pip install excel-to-sql
```

## From Source

```bash
git clone https://github.com/wareflowx/excel-to-sql.git
cd excel-to-sql
pip install -e .
```

## Verify Installation

```bash
excel-to-sql version
# Output: excel-to-sql v0.4.1
```

## Python SDK Verification

```python
import excel_to_sql
print(excel_to_sql.__version__)
```

## System Requirements

- **Python**: 3.10 or higher
- **OS**: Windows, macOS, or Linux
- **Dependencies**: Automatically installed

## Virtual Environments (Recommended)

```bash
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install excel-to-sql
```

## Troubleshooting

**"python: command not found"**
Use `python3` instead of `python`

**"Permission denied"**
Use `pip install --user excel-to-sql`

**"Module not found"**
Ensure you're in the correct virtual environment
